Why Infrastructure Transparency Matters

Every time you visit a website, your browser communicates with remote physical servers across the globe. Understanding where your data travels, who owns the hosting infrastructure, and which third-party trackers observe your habits is essential for digital privacy and data sovereignty.

Hidden Tracker Auditing

Websites embed invisible tracking pixels and scripts. NetPin scans page network activity to surface third-party analytics scripts.

Server Geolocation & Jurisdiction

Data protection laws vary by country. NetPin maps the physical hosting server location so you know which jurisdiction governs your data.

Green Hosting Verification

Data centers account for significant global electricity consumption. NetPin verifies whether target servers use renewable energy.

How NetPin Operates

A non-intrusive workflow built on Chrome's Manifest V3 specifications.

Step 1

Install Extension

Download NetPin source from GitHub and load it into any Chromium browser (Chrome, Edge, Brave, Arc) in developer mode.

Step 2

Passive Tab Inspection

Browse the web normally. NetPin's background service worker listens to network navigation events without affecting load times.

Step 3

Decentralized Geolocation Query

NetPin resolves server IPs and queries privacy-preserving nodes for WHOIS, ASN routing, tracker rules, and carbon metrics.

Step 4

Interactive Insights

Click the NetPin extension toolbar icon to view geolocation maps, security scores, tracker details, and exportable logs.

Manual Installation Steps

Follow these four straightforward steps to load NetPin into any Chromium browser:

Clone Code

Clone the repo from GitHub and run npm install in your shell.

2

Execute npm run build to compile extension files into the dist directory.

3

Enable Dev Mode

Open chrome://extensions in Chrome and switch on Developer mode.

4

Load Unpacked

Click "Load unpacked" and select the generated dist directory.

Frequently Asked Questions

What is NetPin?
NetPin is a browser extension that acts as a real-time inspection tool for web infrastructure. Whenever you visit a site, NetPin identifies the physical server geolocation, ASN network provider, WHOIS ownership records, tracking scripts, and data center energy sources.
Why does server location matter for digital privacy?
Physical server locations dictate which national legal frameworks apply to your data. Understanding host jurisdictions helps users assess privacy rights, data retention laws, and legal protections.
Does NetPin store or share my browsing activity?
No. NetPin strictly follows a local-first design. We maintain no central databases, run no analytics tracking scripts, and never collect browsing logs.
How does NetPin detect hidden trackers?
NetPin passively inspects top-level network requests using Manifest V3 web request rules, comparing third-party domain calls against known tracking database definitions.
What is green web hosting awareness?
NetPin checks target IP addresses against sustainable web databases to verify if data centers operate on verified renewable energy sources like wind or solar.
